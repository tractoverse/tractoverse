# tractoverse: The Tractoverse

The tractoverse is a curated collection of R packages for the analysis
of diffusion MRI tractography data, inspired by the tidyverse.
Installing this meta-package installs and attaches the whole family:

## Details

\- \[fiber\]: data structures for tractography data - \[master\]:
simulation of streamlines / bundles / bundle sets with microstructural
parameters - \[rtists\]: visualization - \[riot\]: data I/O (through
rvtk) - \[toad\]: Tractography Open Atlases Data (companion dataset
package) - \[bot\]: bundle optimal transport; statistical methods for
tractography data

The package also ships the shared tractoverse brand as the single source
of truth: colors, theme and logo family, reused by the individual
package websites and applications (see \[tractoverse_brand()\]).
